# Asset guide

No external assets are approved yet. Use clean procedural or geometric placeholders until a source and license have been verified.

## Player base character

- Search terms: stylized fantasy humanoid rigged GLB, game-ready fantasy humanoid
- Format: GLB or GLTF
- Quality: optimized, animation-compatible, suitable for web and mobile
- Rig: humanoid skeleton with documented animation compatibility
- License: commercially usable, attribution requirements recorded
- Destination: assets/characters/base/

## Lumenfall environment kit

- Search terms: stylized fantasy village GLB, cozy fantasy environment kit
- Format: GLB or GLTF, with compressed textures where available
- Quality: modular, low-to-mid poly, readable silhouettes, mobile-conscious
- Rig: not required
- License: commercially usable, source and creator verified
- Destination: assets/environments/lumenfall/

## Placeholder rule

When an asset is missing, keep the code path stable and mark the placeholder with TODO(ASSET). Never invent a copyrighted asset or claim a license that has not been checked.
