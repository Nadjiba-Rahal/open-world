# Asset manifest

Every external asset must be recorded here before it enters the repository.

| Asset ID | File path | Source | Creator | License | URL | Usage | Status |
| --- | --- | --- | --- | --- | --- | --- | --- |
| None | None | None | None | None | None | No external assets included | Open |

Status values should be Open, Reviewing, Approved, Rejected, or Replaced. Do not call an asset free unless its license is verified.
