# Assets

The asset tree is reserved for verified, legally usable game assets. No external assets are included in Phase 0.

Planned destinations:

~~~text
characters/  animations/  environments/  buildings/  furniture/
creatures/   items/       audio/         vfx/       ui/
~~~

Before adding a file, record its source, creator, license, URL, usage, and status in docs/ASSET_MANIFEST.md and docs/ASSET_LICENSES.md. See docs/ASSET_GUIDE.md for placeholder requirements.
